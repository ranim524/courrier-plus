# API Reference — Courrier+

Full interactive documentation is auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc`
when the backend is running. This page summarizes the endpoints for quick reference.

All responses use a consistent error shape on failure: `{"detail": "..."}`.

## Public — Letters & Payment

| Method | Path | Description |
|---|---|---|
| POST | `/api/letters` | Create a letter (multipart form: sender/recipient fields, subject, message OR `document` PDF file). Returns `201`. |
| POST | `/api/payments/create` | Start payment for a letter (`{"letter_id": "..."}`). Returns `201`. |
| POST | `/api/payments/mock/confirm` | Dev-only mock payment confirmation (`{"transaction_id", "outcome": "success"|"failure"}`). Idempotent. |
| POST | `/api/payments/webhook` | Generic webhook entry point (same shape/idempotency as mock confirm), reserved for a future real provider. |
| GET | `/api/config` | Public config: current letter price and currency. |

## Public — Tracking & Recipient Access

| Method | Path | Description |
|---|---|---|
| GET | `/api/track/{reference}` | Public tracking info + event timeline for a letter reference. |
| GET | `/api/access/{token}` | Validates a recipient access token, records an access event, returns letter content. |
| POST | `/api/access/{token}/open` | Marks the letter as `OPENED`, notifies the sender by email. |
| POST | `/api/access/{token}/receive` | Marks the letter as `RECEIVED`, notifies the sender by email. |
| GET | `/api/access/{token}/document` | Streams the attached PDF, if any, for a valid token. |

## Admin (JWT-protected, `Authorization: Bearer <token>`)

| Method | Path | Description |
|---|---|---|
| POST | `/api/admin/login` | `{"email", "password"}` → `{"access_token", "token_type", "expires_in_minutes"}`. |
| GET | `/api/admin/dashboard` | Aggregate counts per status + payment totals. |
| GET | `/api/admin/letters` | Paginated, filterable (`status`, `search`, `page`, `page_size`) letter list. |
| GET | `/api/admin/letters/{id}` | Full letter detail, including document metadata (SHA-256, size, filename). Records `ADMIN_VIEWED_LETTER`. |
| GET | `/api/admin/letters/{id}/events` | Audit event timeline for a letter. |
| GET | `/api/admin/letters/{id}/emails` | Email delivery history for a letter. |
| GET | `/api/admin/letters/{id}/document` | Streams the attached PDF (admin-authorized). |
| GET | `/api/admin/payments` | Paginated payment list. |
| GET | `/api/admin/emails` | Paginated email event list across all letters. |

## Health

| Method | Path | Description |
|---|---|---|
| GET | `/api/health` | Liveness check. |

## Status codes

- `201` — resource created (letter, payment)
- `200` — successful read/action
- `401` — missing/invalid admin JWT
- `404` — resource not found (letter, invalid access token, invalid reference)
- `409` — invalid state transition (e.g. confirming receipt before the letter was opened)
- `410` — expired access token
- `422` — validation error (bad input, invalid file, missing field)
- `429` — rate limit exceeded
